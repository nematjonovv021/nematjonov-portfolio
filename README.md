# Nematjonov.dev | Shaxsiy portfolio sayti

Bu **Nematjonov Muhammadi** ning shaxsiy portfolio sayti. Sayt HTML va CSS yordamida yozilgan, qorong'i dizaynda, kompyuter va telefon ekranlariga moslashadi.

🔗 **Jonli sayt:** [nematjonov-dev.netlify.app](https://nematjonov-dev.netlify.app)

## Sayt bo'limlari

- **Bosh sahifa**: qisqa tanishtiruv va rasm
- **Men haqimda**: kim ekanligim, qayerda o'qiyotganim va maqsadlarim
- **Ko'nikmalar**: bilgan texnologiyalarim va o'rganmoqchi bo'lganlarim
- **Bog'lanish**: Telegram, GitHub va email havolalari

## Xususiyatlar

- Qorong'i rangli, zamonaviy dizayn
- Mobil va kompyuter ekranlariga moslashuvchan (responsive) ko'rinish
- Navigatsiya havolalari orqali bo'limlarga tez o'tish
- Tugma va kartalarda hover effektlari

## Ishlatilgan texnologiyalar

- **HTML5**: sahifa tuzilmasi
- **CSS3**: dizayn, Flexbox va media query'lar
- **Google Fonts**: Poppins shrifti
- **Git va GitHub**: versiyalarni boshqarish
- **Netlify**: saytni internetga chiqarish

## Loyiha tuzilmasi

```
.
├── index.html    # Sahifaning asosiy kodi
├── style.css     # Dizayn va moslashuvchan ko'rinish
├── code.jpg      # Bosh sahifadagi rasm
└── README.md     # Loyiha haqida ma'lumot
```

## Kompyuterda ishga tushirish

1. Loyihani yuklab oling:

   ```bash
   git clone https://github.com/nematjonov021/nematjonov-portfolio.git
   ```

2. Loyiha papkasiga kiring va `index.html` faylini brauzerda oching.

   Yoki VS Code'da **Live Server** kengaytmasi orqali ishga tushiring: `index.html` ustiga o'ng tugma bosib, **Open with Live Server** ni tanlang.

## Internetga chiqarish

Loyiha GitHub repozitoriyasiga ulangan, shuning uchun Netlify o'zgarishlarni avtomatik joylaydi:

```bash
git add .
git commit -m "O'zgarish haqida qisqa xabar"
git push
```

`git push` dan keyin Netlify yangi versiyani 1-2 daqiqada nashr qiladi.
