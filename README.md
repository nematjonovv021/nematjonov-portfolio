## 🌍 Internetga chiqarish

Loyiha GitHub repozitoriyasiga ulangan, shuning uchun Netlify o'zgarishlarni avtomatik joylaydi:

```bash
git add .
git commit -m "O'zgarish haqida qisqa xabar"
git push
```

`git push` dan keyin Netlify yangi versiyani 1-2 daqiqada nashr qiladi.
